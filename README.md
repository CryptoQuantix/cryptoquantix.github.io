# CryptoQuantix Website

This repository hosts the official website for CryptoQuantix, a quantitative trading engine for crypto perpetuals. 
The site is built with **Jekyll** and deployed on GitHub Pages.

## Quick Start

1. Install Ruby and Bundler
2. `bundle install`
3. `bundle exec jekyll serve`

For the main bot repository, visit: [https://github.com/CryptoQuantix/CryptoQuantix](https://github.com/CryptoQuantix/CryptoQuantix)
